# garantie.tn

Plateforme tunisienne de gestion et de consultation des garanties.

## Interface
- Accueil responsive pour mobile et ordinateur.
- Navigation mobile compacte avec menu déroulant.
- Espace client et interface d'administration.
- Interface optimisée pour les écrans mobiles.

## Déploiement
Le site est publié avec Cloudflare Pages depuis la branche `feature/espace-client`.
